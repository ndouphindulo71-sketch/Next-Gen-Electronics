# Next Gen Electronics

## Project Overview

Next Gen Electronics is a responsive electronics website designed to provide users with an easy and convenient way to explore electronic products and learn more about the business.

The website was developed using HTML5 and CSS3. It includes multiple pages with consistent navigation, responsive layouts, product information, a product gallery and a contact form.

## Website Pages

The website consists of the following pages:

* **Home** – Introduces Next Gen Electronics and provides links to the main sections of the website.
* **About** – Provides information about the business, including its mission, vision and reasons to choose the business.
* **Products** – Displays electronic products with product descriptions and pricing.
* **Gallery** – Displays images of the electronic products.
* **Contact** – Provides contact information and a form that allows users to enter an enquiry.

## CSS Structure

The website uses one external stylesheet located in the `CSS` folder:

`CSS/style.css`

The stylesheet contains the general styling, navigation, buttons, page layouts, product cards, gallery, contact form, footer and responsive media queries.

## Image Structure

Website images are stored in the `Images` folder.

The HTML pages use relative image paths such as:

`Images/phone.jpg`

Responsive images were implemented using `srcset` and `sizes` to provide responsive image information to the browser.

## Testing

The website was tested by navigating through all five pages and checking that the navigation links work correctly.

The website was also tested at desktop, tablet and mobile screen sizes.

The following areas were checked:

* Navigation links
* Page layouts
* Product images
* Gallery images
* Buttons and links
* Contact form
* Responsive layouts

* Footer

All pages were checked to ensure that the website remains usable at different screen sizes.
